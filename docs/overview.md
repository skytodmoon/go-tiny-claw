# Go Tiny Claw - 项目概述

## 核心理念

**"能慢思考、会用工具、能推进任务"** 的 AI Agent 框架。

## 版本规划

### Level 1（基础能力）
- 慢思考（Thinking 阶段）
- 工具调用
- 单次任务执行

### Level 2（进阶能力）
- 结构化思考
- 多步执行
- 动态工具选择

### Level 3（对标业界）
- 四阶段循环（Thinking → Acting → Observation → Re-thinking）
- 动态上下文组装
- 自动压缩机制

## 核心功能

- 多 Provider 支持
- 上下文管理
- 工具注册表（文件读写、编辑、Bash）
- 日志系统
