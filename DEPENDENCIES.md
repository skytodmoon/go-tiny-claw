# Project Dependencies

This document lists the dependencies used in the project along with their purposes.

## Direct Dependencies

1. **github.com/anthropics/anthropic-sdk-go v1.38.0**  
   - Purpose: SDK for interacting with Anthropic services or APIs.

2. **github.com/openai/openai-go/v3 v3.33.0**  
   - Purpose: SDK for interacting with OpenAI services or APIs.
