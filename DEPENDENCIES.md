# Project Dependencies

This document lists the dependencies of the project along with their versions and purposes.

## Direct Dependencies

1. **github.com/anthropics/anthropic-sdk-go (v1.38.0)**
   - Purpose: Anthropic SDK for integrating AI-related functionalities.

2. **github.com/openai/openai-go/v3 (v3.33.0)**
   - Purpose: OpenAI SDK for interacting with OpenAI services.

## Indirect Dependencies

1. **github.com/bahlo/generic-list-go (v0.2.0)**
   - Purpose: Provides generic list implementations.

2. **github.com/buger/jsonparser (v1.1.2)**
   - Purpose: High-performance JSON parser for Go.

3. **github.com/invopop/jsonschema (v0.13.0)**
   - Purpose: JSON Schema generation for Go types.

4. **github.com/mailru/easyjson (v0.7.7)**
   - Purpose: Fast JSON serializer/deserializer.

5. **github.com/tidwall/gjson (v1.18.0)**
   - Purpose: Get JSON values quickly.

6. **github.com/tidwall/match (v1.1.1)**
   - Purpose: Pattern matching for strings.

7. **github.com/tidwall/pretty (v1.2.1)**
   - Purpose: Pretty-print JSON.

8. **github.com/tidwall/sjson (v1.2.5)**
   - Purpose: Set JSON values quickly.

9. **github.com/wk8/go-ordered-map/v2 (v2.1.8)**
   - Purpose: Ordered map implementation for Go.

10. **golang.org/x/sync (v0.16.0)**
    - Purpose: Provides synchronization primitives.

11. **gopkg.in/yaml.v3 (v3.0.1)**
    - Purpose: YAML support for Go.
