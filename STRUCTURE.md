# Project Directory Structure and Purpose

Below is an overview of the project directory structure along with the purpose of each directory and file.

## Root Directory
- `ABSTRACT.md`: Contains an abstract or summary of the project.
- `ANALYSIS.md`: Analysis documentation for the project.
- `CHANGELOG.md`: Records changes and updates made to the project.
- `DEPENDENCIES.md`: Lists the dependencies of the project.
- `HOMEWORK_SUBMISSION.md`: Documentation related to homework submissions.
- `MISSING_FILE.md`: Specifies files that are missing or need attention.
- `Makefile`: Contains build automation instructions.
- `NOTES.md`: Miscellaneous notes related to the project.
- `README.md`: Main README file providing an overview of the project.
- `README_table.md`: Additional README file with tabular data.
- `README_updated.md`: Updated version of the README file.
- `REVIEW.md`: Contains review notes or feedback.
- `STRUCTURE.md`: This file, documenting the directory structure.
- `SUMMARY.md`: Summary or highlights of the project.
- `TESTING.md`: Documentation related to testing procedures.
- `TEST_REPORT.md`: Reports on test results.
- `TODO.md`: Lists pending tasks or features to be implemented.
- `batch_rename.sh`: Script for batch renaming files.
- `cmd`: Contains the command-line applications of the project.
- `config.yaml`: Configuration file for the project.
- `docs`: Documentation files.
- `go.mod`: Go module file specifying dependencies.
- `go.sum`: Checksum file for Go module dependencies.
- `hello`: Likely a test or example binary.
- `hello.go`: Sample Go program.
- `hello.txt`: Sample text file.
- `helloworld.go`: Another sample Go program.
- `integration`: Integration testing files.
- `internal`: Internal packages and modules.
- `logs`: Log files generated by the application.
- `main`: Main application files.
- `scripts`: Utility scripts.
- `testutils`: Utilities for testing.

### `cmd` Directory
Contains command-line applications:
- `claw`: Main command-line application.
  - `main.go`: Entry point for the claw application.
- `level3-test`: Test-related command-line application.
  - `main.go`: Entry point for the level3-test application.
- `task-runner`: Task runner command-line application.
  - `main.go`: Entry point for the task-runner application.

### `docs` Directory
Contains project documentation:
- `api.md`: API documentation.
- `example.md`: Example usage documentation.
- `overview.md`: High-level overview of the project.

### `integration` Directory
Contains integration test files:
- `level3_integration_test.go`: Integration tests for level3.

### `internal` Directory
Contains internal packages:
- `context`: Context-related functionality.
  - `context.go`: Context implementation.
- `engine`: Engine or core logic.
  - `loop.go`: Core loop implementation.
  - `loop_test.go`: Tests for the core loop.
- `feishu`: Feishu-related functionality.
  - `feishu.go`: Feishu implementation.
- `logger`: Logging functionality.
  - `logger.go`: Logger implementation.
- `memory`: Memory-related functionality.
  - `memory.go`: Memory implementation.
- `provider`: Provider-related functionality.
  - `claude.go`: Claude provider implementation.
  - `deepseek.go`: Deepseek provider implementation.
  - `glm47.go`: GLM47 provider implementation.
  - `interface.go`: Provider interface.
  - `minimax.go`: Minimax provider implementation.
  - `openai.go`: OpenAI provider implementation.
  - `siliconflow.go`: Siliconflow provider implementation.
- `schema`: Schema-related functionality.
  - `message.go`: Message schema implementation.
- `tools`: Utility tools.
  - `bash.go`: Bash tool implementation.
  - `edit_file.go`: File editing tool.
  - `read_file.go`: File reading tool.
  - `registry.go`: Registry implementation.
  - `tools_test.go`: Tests for tools.
  - `write_file.go`: File writing tool.

### `logs` Directory
Contains log files:
- `claw-2026-05-04.log`: Log file for the claw application.

### `scripts` Directory
Contains utility scripts:
- `test-e2e.sh`: End-to-end test script.

### `testutils` Directory
Contains testing utilities:
- `mock_provider.go`: Mock provider for testing.
- `test_helpers.go`: Helper functions for tests.
