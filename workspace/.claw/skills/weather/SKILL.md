# 天气查询技能

## 使用方法
**直接使用 `bash` 工具**执行以下命令：

```bash
# 查询指定城市天气（推荐）
curl -s "https://wttr.in/城市名?format=3"

# 示例：查询北京天气
curl -s "https://wttr.in/北京?format=3"

# 查询详细天气
curl -s "https://wttr.in/北京" | head -20
```

## 支持的城市
- 北京、上海、广州、深圳、杭州、成都、重庆、武汉、青岛等

## 返回示例
```
北京: 🌤️  +25°C
```

## 注意事项
- 使用 `bash` 工具执行上述命令，**不要调用不存在的工具**
- wttr.in 支持中文城市名
- 确保网络连接正常
